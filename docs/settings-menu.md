# Aura settings navigation

The settings hierarchy follows the supplied reference screenshots: Settings, Miscellaneous and About groups; an Interface submenu with collapsible sections; a Playback submenu with dedicated output, playback, automatic actions, transitions, headset and notification pages; and an Offline/cache/download category.

The layout uses compact outline icons, muted blue-gray grouped surfaces, separators and pale-blue section headings. Aura retains its name and assets, with wording from the selected app language. Support/promotional cards from the reference application are not reproduced as Aura services.

Implemented destinations keep their existing behavior: player volume, speed, sleep timer, crossfade/fades, Android EQ, headset commands, media notification buttons, star size, library filters, source management and listening history. Output and playback pages expose their own controls; headset and notification settings no longer require opening a combined page.

Unavailable features are disabled and labeled `În pregătire` in Romanian: advanced decoding/audio focus, Android Auto, automatic server caching and store/support links. [Theme/font/color customization](appearance.md) is available under Interface. [Navigation and start-screen preferences](navigation.md) are also available under Interface. [Home/Library/Album/Artist/Genre/Playlist/Search page preferences](library-pages.md) are available under Page settings. [Twenty app languages](localization.md) can be selected from the main settings menu, alongside backup/restore; see [its format and behavior](backup-restore.md). Menu structure is not a claim that the disabled capabilities are implemented.

The widget navigation test uses an in-memory music store and a fake audio player on a 320-pixel-wide display. It checks disabled actions, collapsible sections, access to star sizing, separate volume/speed pages, back navigation and the source-management callback. No test uses live phone data.

Individual Navidrome downloads and their management are available under Offline files; see [offline downloads](offline-downloads.md).

Generated backups, playlist JSON exports and opt-in diagnostic reports are available under [Generated files](generated-files.md).
